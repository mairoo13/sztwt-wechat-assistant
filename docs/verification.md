## 离线测试

`python -m unittest discover -s tests -v`：10 项通过。覆盖精确日期/星期、同周限制、刷新间隔、无名额/无目标日期、资料变化停止、停止指令、只提交一次、结果不明保留提交锁以及重复提交防护。

测试使用模拟页面与临时状态目录，不会访问官方预约网站。它们用于验证任务逻辑，不能代替真实微信控件与服务端验证。
